# PocketBudget Project Report

## 1. Project title

**PocketBudget — Personal Expense Tracker and Budget Advisor**

## 2. Abstract

PocketBudget is a Python command-line application for recording expenses and
income, setting monthly category budgets, and reviewing personal finances.
Transactions and budgets are stored in JSON files. Pandas powers the reports
and CSV export; Matplotlib creates monthly charts. Pillow renders
documentation screenshots from actual terminal output and temporary demo data.
A rule-based advisor gives simple budgeting suggestions.

## 3. Problem statement and objectives

Daily purchases can be difficult to remember, and spending may pass a planned
limit before the end of a month. PocketBudget provides a local, terminal-based
way to record transactions, monitor category limits, and understand spending.
The project demonstrates modular Python, validation, JSON file handling,
analysis, charts, and automated testing.

## 4. Scope and constraints

PocketBudget is a local learning project. It uses no database, web framework,
GUI, external API, or login system. The application stores data in JSON files
and displays its interface using terminal input and output. The advisor
provides general educational suggestions, not professional financial advice.

## 5. Main features

1. Add, view, edit, search, and confirm before deleting expenses.
2. Record income and view income independently of expenses.
3. Calculate monthly income, expenses, current balance, savings, and savings
   percentage.
4. Set monthly budgets for expense categories and identify overspending.
5. Generate category, weekly, daily, average-spend, highest-day, and top-three
   reports.
6. Export a month's expenses as an Excel-friendly CSV file.
7. Save five category, trend, budget, and savings charts.
8. Provide financial suggestions based on spending and savings.

## 6. Data design

`data/expenses.json` stores both expenses and income in a list. IDs are
positive integers shared across both record types. Expense records include
`id`, `type`, `amount`, `category`, `date`, `description`, and
`payment_method`. Income records include `id`, `type`, `amount`, `date`,
`description`, and `source`.

An expense example is:

```json
{
  "id": 1,
  "type": "expense",
  "amount": 250.0,
  "category": "Food",
  "date": "2026-11-17",
  "description": "Lunch and snacks",
  "payment_method": "UPI"
}
```

`data/budgets.json` maps a month directly to category limits:

```json
{
  "2026-11": {
    "Food": 3000.0,
    "Travel": 1500.0
  }
}
```

JSON writes are atomic, and a backup is created before an existing data file
is replaced. The application initializes missing JSON files and reports
corrupted data without silently overwriting it.

## 7. Module design

| Module | Responsibility |
| --- | --- |
| `main.py` | Initializes storage and routes the exact terminal menu choices. |
| `constants.py` | Defines paths, categories, menu labels, colors, and messages. |
| `terminal_ui.py` | Prints consistent terminal headings and messages. |
| `validations.py` | Validates amounts, dates, months, categories, IDs, and payments. |
| `file_handler.py` | Loads, validates, migrates, backs up, and saves JSON data. |
| `expense_manager.py` | Implements expense entry, viewing, editing, search, and deletion. |
| `income_manager.py` | Implements income entry and viewing. |
| `budget_manager.py` | Sets category budgets and calculates budget status. |
| `analytics.py` | Produces Pandas reports and monthly CSV exports. |
| `visualizations.py` | Generates the five monthly Matplotlib charts. |
| `advisor.py` | Summarizes finances and creates rule-based suggestions. |
| `scripts/generate_screenshots.py` | Builds README images without touching user data. |

## 8. Input validation and error handling

Amounts must be positive finite numbers. Dates and months must be valid
calendar values in `YYYY-MM-DD` and `YYYY-MM` formats. Categories and payment
methods must be selected from their supported values. Invalid input is
re-prompted. Missing JSON files are initialized; invalid JSON and invalid
records are reported rather than silently discarded.

## 9. Testing

The pytest suite covers validation, category totals, budget calculations,
savings, highest-spending days, JSON initialization and backups, transaction
migration, CSV export, chart generation, and menu configuration. Storage and
export tests use temporary directories and do not touch the user's project
data. Run from the project root:

```powershell
python -m pytest -v
```

README screenshots are generated by running
`python scripts/generate_screenshots.py`. That script builds a temporary demo
dataset, calls the application's reporting and chart functions, and renders
terminal output with Pillow. It writes images only to `docs/screenshots/`.

## 10. Run the application

Install dependencies and start the terminal menu:

```powershell
python -m pip install -r requirements.txt
python main.py
```

## 11. Limitations and future improvements

PocketBudget is local and single-user, does not convert currencies, and uses
simple fixed-rule guidance. Future improvements could include recurring
transactions, more report periods, optional encrypted backups, and additional
currency formatting while keeping the terminal-only interface.
